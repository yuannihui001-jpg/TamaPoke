# TamaPoke v2.37.0 OTA、触摸音与成长修正版

- 更新按钮按下后立即显示状态，联网检查和固件下载延后执行，避免触摸后长时间像无响应。
- OTA 检查增加 TLS 握手等待、首次失败重试和完整中文弹窗；官方固件仍可直接在线更新。
- 全部轻触统一播放点击音，设置页新增独立的“触摸音量”小、中、大选择。
- 中文字体表补充全角标点和常用符号，避免未收录字符显示成问号。
- 宠物动画改用小数比例像素边界缩放，在保持像素风格的同时减少放大后的粗糙大色块。
- 宠物体重会随等级成长，并缓慢回到当前阶段的健康目标；食物与训练仍会改变体重。
- 装备详情页宠物整体上移并保持水平居中。
- 游戏页移除底部每日任务行。
- 商店每页固定显示 5 件商品，左右滑动按整页切换。

整包首次刷写使用 `01-flashable/tamapoke-2.37.0-merged.bin`。

仅更新应用分区使用 `01-flashable/tamapoke-2.37.0-app.bin`。OTA 更新不会擦除宠物和游戏资料。
