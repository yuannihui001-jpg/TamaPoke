# TamaPoke v2.34.0 自动 OTA 与场景布置修正版

- 官方固件在线更新：设备点击更新时自动连接已保存 WiFi，携带固件内置发布证明检查并下载新版，不再输入许可码，也不会出现“设备未登记”。
- 浏览器首次安装仍由作者许可接口保护；在线服务只返回加密镜像。
- 道具购买后永久保留在仓库，布置页按页显示已拥有道具，可分别点击“布置”和“收回”，当前场景按固定网格绘制已布置道具，避免重叠。
- 装备页采用顶部居中、左右两列的槽位布局，宠物居中显示，参数移到下方避免重叠。
- 睡眠状态继续计时成长，但屏幕背光为最低并降低刷新频率；触摸只短暂微亮。

刷写整包时使用 `01-flashable/tamapoke-2.34.0-merged.bin`；仅更新应用分区时使用 `01-flashable/tamapoke-2.34.0-app.bin`。
