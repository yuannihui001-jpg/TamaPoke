# TamaPoke v2.29.0 严格授权版

本目录是 ESP32-S3 Touch AMOLED 1.75 的完整发布包，包含本地刷写镜像、在线服务加密镜像、源码快照和校验记录。

## 文件夹

- `01-可刷写固件`：本地调试和维护使用的明文固件；`merged` 是首次刷写用的 16 MB 合并镜像，`app` 只适用于已有同分区固件的 OTA/应用更新。
- `02-在线服务加密镜像`：Cloudflare Worker 使用的 AES-GCM 加密文件，不能直接刷写。
- `03-源码快照`：生成此版本固件所用的主要源码和网页清单。
- `04-说明与校验`：版本说明、部署说明和 SHA256 校验值。

## 浏览器安装

使用 Chrome 打开仓库的 Pages 安装页，连接开发板并选择串口后开始安装。首次给新设备授权仍需要作者许可码；已保存授权令牌的设备可以直接检查并安装新版本。

## 在线升级

设置页的“更新”按钮调用严格授权 Worker 的设备更新接口。升级只写入应用分区，不擦除 NVS，因此宠物、金币、仓库和 WiFi 配置会保留。设备需要联网，且必须已经完成过一次授权绑定。

## 本版重点

- 中文默认语言，中文字体资源已重新生成。
- WiFi 扫描、密码删除键、连接/关闭切换。
- 版本检查弹窗和已授权设备免重复输入许可码的 OTA 流程。
- 设备设置、装备仓库、野外捕获烟花效果及天气时区显示调整。
