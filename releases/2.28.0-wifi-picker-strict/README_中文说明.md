# TamaPoke v2.28.0 Wi-Fi 设置与电源优化版

本目录是本次固件的统一版本归档，包含源码快照、加密固件、配置说明和校验值。

## 本次改动

- 设置页 Wi-Fi 按钮会扫描附近网络，选择网络后进入密码键盘，可返回或确认连接。
- 设置页整体重新排版，亮度、音量、触摸灵敏度、语言、Wi-Fi 和版本信息均留在圆形屏幕安全区域内。
- 装备页调整为紧凑五行布局，并补充中文字体字形，避免显示问号。
- PWR 短按只切换屏幕灯光；AXP2101 长按约 6 秒关机，再长按开机。AXP2101 硬件没有精确 5 秒档位，6 秒是可用的最近档位。

## 刷写与 OTA

- `TamaPoke-v2.28.0-merged.bin`、`TamaPoke-v2.28.0-app.bin` 等明文镜像只保存在本机，不上传到公开仓库。
- `tamapoke-2.28.0-merged.bin.enc` 和 `tamapoke-2.28.0-app.bin.enc` 是授权服务使用的加密镜像。
- 浏览器入口：<https://tamapoke-license.yuannihui001.workers.dev/>

校验值见 `SHA256_校验.txt`。编译和下载测试均使用同一版本 `2.28.0`。
