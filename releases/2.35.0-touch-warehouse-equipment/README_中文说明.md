# TamaPoke v2.35.0 触摸、仓库与装备修正版

- 更新按钮扩大触摸区域并优先响应，不再被旧提示弹窗吞掉第一次点击。
- 连接更新服务时只重试 HTTPS 请求，不再主动关闭或重新开启 WiFi。
- 网络提示使用圆屏中央弹窗和完整 25x25 粗体中文字库。
- 布置页整体移入圆屏安全显示区；仓库中的已购道具可直接布置或收回。
- 主页场景道具按物品用途放置，背景物靠近地平线、家具和玩具落在地面。
- 仓库中点击任意物品会打开详情，显示图标、效果、数量以及可用操作。
- 宠物装备页不再显示“空”和“在用”；点击部位后直接选择仓库装备，也可卸下。

整包首次刷写使用 `01-flashable/tamapoke-2.35.0-merged.bin`。

仅更新应用分区使用 `01-flashable/tamapoke-2.35.0-app.bin`。OTA 更新不会擦除宠物和游戏资料。
