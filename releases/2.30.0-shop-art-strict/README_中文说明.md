# TamaPoke v2.30.0 商店物品画风版

本目录是 ESP32-S3 Touch AMOLED 1.75 的完整发布包，包含本地刷写镜像、在线服务加密镜像、源码快照、120 项商店素材和校验记录。

## 文件夹

- `01-可刷写固件`：本地维护使用的明文固件；`merged` 用于首次完整刷写，`app` 用于已有相同分区固件的应用更新。
- `02-在线服务加密镜像`：Cloudflare Worker 使用的 AES-GCM 加密文件，不能直接刷写。
- `03-源码快照`：生成本版固件所用的源码、商店素材、生成工具和网页清单。
- `04-说明与校验`：版本说明、部署说明和 SHA256 校验值。

## 本版重点

- 商店六大类共 120 项物品全部换成统一电子宠物卡通画风。
- 食品、玩具、药品、装备和道具使用真实物体轮廓，旅游项目使用对应景点建筑轮廓。
- 商店列表使用清晰的 32x32 像素图，商品详情使用同源 96x96 放大图。
- 商店、详情、仓库、喂食、玩具选择和装备页共用同一套商品编号与图片。
- 图标采用 16 色 RGB565 调色板和 4 位像素索引，保持低内存占用。

## 升级与存档

已授权设备可在设置页连接 WiFi 后直接检查更新，无需再次输入作者许可码。OTA 只写入应用分区，不擦除 NVS，宠物、金币、仓库、装备、WiFi 和授权令牌会保留。

首次给新设备安装仍需在浏览器安装页输入有效作者许可码。
