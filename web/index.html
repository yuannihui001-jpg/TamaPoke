🐢 TamaPoke 中文固件

适用于微雪 ESP32-S3-Touch-AMOLED-1.75。使用电脑 Chrome 选择串口后即可安装，无需 Arduino。

请使用 USB-C 数据线，并从 http://localhost 或 HTTPS 地址打开本页；直接双击 HTML 文件会被浏览器禁止访问串口。

⚠️ 当前浏览器不支持串口安装，请使用电脑端 Chrome 或 Edge。

1安装中文固件

用 USB-C 数据线连接开发板，点击下面的按钮，选择开发板对应的串口并等待完成。

浏览器不支持，请使用电脑端 Chrome 或 Edge。 请通过 HTTPS 或 localhost 打开本页面。

🔄 已经在使用旧版本时，建议选择“不擦除”以保留宠物存档。第一次安装或需要彻底重置时才选择“擦除设备”。

2加载精灵资源到 microSD

插入 microSD 卡后点击“连接开发板”，再点击“加载精灵”。资源会通过 USB 自动写入（约 42 MB，需要几分钟），期间不要拔卡。

加载资源前请先关闭第 1 步的安装弹窗或页面，因为同一时间只能有一个程序占用串口。

有自己的 .bin 文件？

🎨 自定义精灵制作方法见 项目说明。


  


  
3Wi-Fi 与在线更新

  

    
先用串口监视器发送 WIFI 家庭WiFi密码 格式的命令保存网络（名称和密码之间留一个空格），然后在设备下滑设置页点击“连接 WiFi”。连接成功后点击“更新”，设备会从 TamaPoke 在线固件通道下载应用更新并自动重启。

    
完整刷写仍建议使用第 1 步的 USB 安装；在线更新只替换应用分区，不会覆盖宠物存档和 microSD 精灵资源。在线更新地址已固定为 raw.githubusercontent.com/yuannihui001-jpg/TamaPoke/main/web/firmware/tamapoke-app.bin，发布新版本时将新的应用镜像放到该路径即可。
